# AI Usage

This project was developed with AI assistance (coding agent) used as a supporting tool.

Scope of AI help:
- Initial design draft (interface, in-memory implementation, ordering rules).
- Draft implementation and JUnit 5 tests, including the example ordering scenario.
- Documentation drafts (`README.md`, this file).

All generated code was reviewed, adjusted, and verified by running `mvn clean verify` (all tests green).

Final decisions (Java 17, Maven layout, `findMatchesByTeam` as the extra operation, validation and ordering rules) were made by the author.
